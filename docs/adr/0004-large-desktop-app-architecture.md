# Support Large Local-First Desktop Applications with Capability-Scoped Services, Typed Memory Routing, and Workbench Primitives

**Status:** accepted

ADR-0002 established `zgui-js` as a domain-agnostic UI framework for multi-surface Wayland shells and lightweight tools, keeping `@hewel/zgui-services` limited to read-only package assets, Unix domain sockets, allowlisted commands, and inbound control messages. Building real-world, large-scale local productivity and workbench applications (Markdown/code editors, note studios, system monitors, developer tools) exposes seven structural gaps that cannot be solved cleanly by shelling out to ad-hoc subprocesses: imperative scrolling, ergonomic text selection control, clipboard access, structured client-side routing, local persistence, user-authorized local file I/O, and workbench-grade layout/window primitives.

We will extend `zgui-js` in two waves with **Linux / Wayland as the first-class target** while keeping every JavaScript API **platform-neutral** (never leaking XDG or Wayland-specific concepts into public JS contracts), strictly preserving **Capability-First + user-gesture authority** and **zero-environment-leak deterministic previews** (`Fixture runtime` / in-memory simulation for every new service).

## Wave 1: Local Workbench Closed Loop

1. **Programmatic scrolling (`@hewel/zgui` + `ui-bridge`):** Bridge `zgui-view`'s existing `ViewHost::scroll_to` (`IntoView`, `IntoViewStart`, `IntoViewEnd`, `IntoViewCenter`, `Offset`, `By`, `Instant`, `Smooth`), converting CSS px to device px via `host.scale()`. Expose `scrollTo`, `scrollBy`, and `scrollIntoView` (downgrading `smooth` to `instant` when `getReducedMotion()` is active) and add `scrollToIndex` to `<VirtualList>` / `<VirtualGrid>`.
2. **UTF-16 text selection contract (`@hewel/zgui` + `ui-bridge`):** Unify all JS-facing text selection indices to JavaScript native **UTF-16 code-unit offsets** (translating to/from Rust UTF-8 byte offsets inside `ui-bridge`) to eliminate CJK/emoji index bugs. Bridge `ViewHost`'s existing `selection`, `set_selection`, and `select_all` as `getSelection`, `setSelection`, and `selectAll`. Read-only `<text>` cross-node selection remains Wave 2.
3. **Clipboard service (`@hewel/zgui-services` + `vendor/zgui-platform-wayland`):** Expose `readText`, `writeText`, `readImage` (returning a host-owned `ImageHandle`), and `writeImage` with an optional `secret` flag (`exclude_from_history`). Omit `FileList` so clipboard cannot bypass file capability boundaries. Reads require either a manifest capability or an active user-gesture context; writes are allowed by default. Extend `vendor/zgui-platform-wayland` with `image/png` MIME negotiation, and wire `vendor/zgui-platform-headless`'s `MemoryClipboard` + preview fixtures for deterministic tests.
4. **Typed multi-instance memory router (`@hewel/zgui/router`):** Ship a zero-dependency Solid 2.0 memory router as a subpath export of `@hewel/zgui`. Favor a typed route-table API (`createRouter(routes)` inferring route paths and params) paired with declarative `<RouterProvider>`, `<Outlet />`, and `<Link>`. Support multiple independent scoped router instances (for multi-tab workspaces, split panes, and auxiliary `WindowSurface`s), nested layouts, forward/back history stacks, `useBeforeLeave` guards, and optional bridging to `onControlMessage`.
5. **Host-managed SQLite with thin KV wrapper (`@hewel/zgui-services` + `host-services`):** Provide per-`appId` SQLite databases stored under `$XDG_DATA_HOME/<appId>/` (and `:memory:` with fixture seeding in preview), executing all queries asynchronously via `HostRequest`/`Promise` off the QuickJS thread so heavy queries never threaten the 100 ms JS turn budget. Enable WAL mode with **read/write separation** (concurrent read connection pool + serialized single writer), FTS5 full-text search, atomic statement batches, and **interactive `transaction(async tx => ...)`** guarded by a host hard timeout (default 5 s, configurable up to 30 s) that automatically rolls back with `E_TX_TIMEOUT` on timeout, uncaught error, or session teardown. Layer a thin typed KV/settings wrapper over the same SQLite engine.
6. **Dual-track local file I/O, dialogs, bookmarks, and directory watching (`@hewel/zgui-services` + `host-services`):** Combine (a) native `openFileDialog` / `saveFileDialog` / `openDirectoryDialog` (via XDG Desktop Portal `FileChooser` on Linux) returning opaque session-scoped `FileHandle`/`DirHandle` capabilities, with (b) manifest-declared directory prefixes (e.g., `$XDG_DOCUMENTS_DIR/notes`) for path-scoped access. Support **persistent handle bookmarks** stored in host-managed, per-`appId` isolated state (`$XDG_STATE_HOME/zgui-host/grants/<appId>.json`, with `listBookmarks` / `revokeBookmark`), enforcing canonical root-boundary checks on `DirHandle` to block symlink escapes and simulating grants + virtual directories in preview fixtures. Provide `readText`, `readBytes`, **atomic** `writeText`/`writeBytes` (temp file + rename), `stat`, `readDir`, `mkdir`, `rename`, `remove`, and owner-scoped debounced `watchDirectory` (`notify`), all bounded by explicit byte limits.
7. **Workbench components and unified window controls (`@hewel/zgui` + `@hewel/zgui/components`):** Add `SplitPane`, `Select` / `Combobox`, `Toast` (backed by existing `OverlayLayer::Toast`), and `TreeView` (`CommandPalette` deferred to Wave 2). Extend single-window `renderApp` sessions with runtime primary-window controls (`setTitle`, `setFullscreen`, `setMaximized`, `setMinimized`, `beginMoveDrag` for frameless titlebars), synchronous close-veto via `onCloseRequest(e => e.preventDefault())` + `window.close({ force: true })` (bridging `zgui-runtime`'s `CloseResponse::Veto`), and on-demand auxiliary `WindowSurface` creation so multi-window apps no longer require rewriting into pure `renderShell`.

Wave 1 is validated end-to-end by graduating `apps/examples/md-editor` into a real local Markdown application (opening/saving local `.md` files and workspace folders with bookmark restore, Outline scroll-to-heading, UTF-16 selection toolbar, code-block clipboard copy, draggable `SplitPane`, and unsaved-changes close veto).

## Wave 2 Roadmap (Ordered)

1. **Network & Drag-and-Drop:** Domain-allowlisted `fetch` / SSE / `WebSocket` plus external and internal DnD (adding hit-tested drop routing in `zgui-runtime` and Wayland drag source support).
2. **Rich Documents & Graphics:** Cross-node selectable read-only `<text>`, `CanvasScene` enhancements (text, gradients, dashes, image blitting), and `CommandPalette`.
3. **Engineering & Scale Tooling:** State-preserving HMR, desktop runtime Inspector/Profiler, bundle code-splitting, and background JS Worker execution.

## Considered Options

- **Keep UTF-8 byte offsets in JS text selection APIs:** Rejected because every JS string operation (`slice`, regex, length) uses UTF-16 code units; forcing every app author to maintain manual `utf8OffsetToUtf16` converters guarantees recurring CJK/emoji bugs.
- **Ship a separate ad-hoc JSON file KV store before SQLite:** Rejected because building and maintaining two separate persistence engines, migration paths, and preview mocks duplicates work; SQLite with WAL + a thin KV wrapper covers preferences, drafts, caches, and FTS5 search from day one.
- **Allow arbitrary filesystem paths after a file dialog or use coarse `allowFs`/`allowNet` booleans:** Rejected because ambient host filesystem/network authority breaks `zgui-js`'s sealed capability model and makes deterministic preview enforcement unenforceable.
- **Use XDG Documents Portal exclusively for persistent file bookmarks:** Rejected because Documents Portal availability and FUSE mount behavior vary across non-Flatpak Linux desktop environments; host-managed per-`appId` grant files with canonical boundary enforcement work uniformly across native Linux/Wayland installs and cleanly mirror preview's in-memory grant table.
- **Adopt `@solidjs/router` directly:** Rejected because it assumes browser DOM `window.location`, `history.pushState`, and `<a>` delegation that do not exist in QuickJS-NG + Native Tree, and assumes a single global URL rather than multi-pane/multi-window scoped stacks.
- **Defer Wayland `image/png` clipboard MIME negotiation to Wave 2:** Rejected because `MemoryClipboard` already supports images and leaving live Wayland returning `UnsupportedFormat` creates an immediate parity gap between preview and desktop runs.

## Consequences

- `crates/ui-bridge` gains a small, explicit breaking change on `NativeValueEvent.selection` (UTF-8 byte offsets → UTF-16 code-unit offsets) during v0.1; all existing examples (`md-editor`, `editing`) and `tests/` must update alongside the change.
- `vendor/zgui-platform-wayland` acquires a documented local patch for `image/png` clipboard MIME negotiation (tracked in `vendor/README.md` and `bun run test:vendor`).
- `crates/host-services` and `crates/native-host` grow two new capability families (`sqlite`, `filesystem` + `clipboard`) with corresponding `manifest.json` schemas, `Fixture runtime` in-memory adapters, and teardown resource counters (`db_transactions`, `fs_watchers`, `file_handles`).
- `packages/ui` exports a new subpath `@hewel/zgui/router`, and `docs/development/component-map.md` will expand to track `SplitPane`, `Select`/`Combobox`, `Toast`, and `TreeView`.
